API da calculadora

As mesmas contas da tela, para usar em outro sistema. As rotas /api/calculadora/… seguem o contrato das APIs oficiais da Receita Federal: um cliente feito para elas funciona trocando só o endereço.

Como chamar

URL base: . Corpo e resposta em JSON. O documento OpenAPI completo está em /api/openapi.json (importe no Postman, Insomnia ou Swagger Editor).


    


    

      
Rotas

      
Cada rota traz uma linha curl com os exemplos do documento: quando há exemplo completo ela roda como está. Sem exemplo, o corpo vem de um arquivo (--data-binary @corpo.json) e os valores a preencher aparecem entre < > ou { }.
